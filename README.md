- Understand programming concepts through practical examples.

- Build a strong foundation for advanced Python learning.

## ⚙️ Requirements

- Python 3 installed on your computer.
- A code editor such as VS Code, or any Python-compatible editor.

## ▶️ How to Run

1. Download or clone this repository.
2. Open the project folder in your code editor.
3. Open any `.py` file.
4. Run it using Python.

Example:

```bash
python variables.py
```
